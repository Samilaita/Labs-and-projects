## Main Projects

### Real-time Football RAG System

A real-time football match streaming system with an AI-powered chatbot.

The project simulates live football matches from structured event data and allows users to ask natural language questions about the match while it is being streamed.

**Main features:**

* Real-time match event streaming
* Kafka-based event pipeline
* AI chatbot using Mistral AI
* FastAPI backend
* Next.js / React frontend
* Context-aware answers based on recent match events

**Folder:** `Real-time-football-rag/`

---

### Capstone License Analyzer

A modular tool for detecting and classifying open-source licenses in GitHub repositories or local projects.

The tool downloads license-related files, scans them with ScanCode, extracts relevant license contexts, and uses an LLM to produce a final license assessment.

**Main features:**

* GitHub repository license analysis
* Local project license analysis
* ScanCode integration
* Mistral AI-based license classification
* JSON and human-readable reports
* Conflict detection between licenses

**Folder:** `capstone-project/`

---

### LSST Time Series Classification

A comparative study on multivariate time series classification using the LSST astronomical dataset.

The project compares a supervised deep learning baseline with a zero-shot foundation model approach based on Chronos embeddings and probe classifiers.

**Main components:**

* Baseline FCN model
* Chronos feature extraction
* SVM probe classifier
* LSST multivariate time series dataset
* Performance comparison and visualization

**Folder:** `time-series-project/`
